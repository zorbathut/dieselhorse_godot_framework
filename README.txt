To set up environment:

* Install Python from https://www.python.org/downloads/
* Install Poetry from https://python-poetry.org/docs/
(Things I wish you didn't have to do but currently do:)
* Install Visual Studio 2022 community from https://visualstudio.microsoft.com/vs/
	* Must include: .NET 6.0 Runtime, .NET SDK, NuGet package manager, C# and Visual Basic Roslyn compilers, C# and Visual Basic development activity

To run the editor:

* Run `build_and_run_editor`
