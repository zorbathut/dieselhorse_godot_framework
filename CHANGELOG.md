## [v0.0.5-pre6alpha]

### Gameplay
* Limit building/mining range.
* Most enemies are now blocked by walls.
* Reduce avatar hurtbox a little.

### UI
* Add error messages when trying to terraform in invalid ways.
* Add realtime preview for terraform actions.
* Item counts are now more visible on light items.

### Improvements
* Multiplayer performance increased significantly (no, multiplayer is not yet supported, sorry).

### Fixes
* Camera no longer passes map bounds.
* Inconsistent flying creature spawn behavior.
* Mouse input alignment bug on resized window.
* SpawnCreature debug command had trouble spawning at exactly the click point.
